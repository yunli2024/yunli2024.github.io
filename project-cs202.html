Single-Cycle
RISC-V CPU

A 32-bit, single-cycle RV32I CPU built with Verilog and Vivado. It implements the complete fetch–decode–execute–memory–write-back path, along with UART-based debugging and four interactive teaching tools for computer organization.

Project Highlights

From the hardware datapath to interactive teaching tools

01 / CORE

Single-Cycle Datapath

Implements the program counter, control unit, register file, immediate generator, ALU, instruction memory, data memory, and write-back selection.

02 / ISA

RV32I Instruction Support

Supports arithmetic and logical operations, immediate instructions, loads, stores, conditional branches, and the JAL/JALR jump paths.

03 / DEBUG

UART Hardware Debugging

Supports CPU halt, single-step, and reset, plus debug access to registers, instruction memory, and data memory.

04 / BONUS

Interactive Learning Tools

Includes four interactive tools covering arithmetic units, cache, RISC-V instruction encoding and decoding, and Hamming SEC/DED.
