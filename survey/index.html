Thank you for participating in this anonymous user study. Please read the instructions below carefully before answering.

This survey contains 10 object-removal tasks. Each task first presents an input image with a red annotation, followed by the final frames produced by six anonymous methods, labeled Result A–F. For each of the five criteria, select the two best results. Please make sure to select exactly two results! The selected pair is not ranked.
