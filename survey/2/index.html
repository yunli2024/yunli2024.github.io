This survey contains 10 object-removal tasks. Each task first presents an input image marked with red lines, which coarsely indicate the complete target to remove rather than its exact boundary. It then shows the removal results produced by six different methods, labeled A–F. We provide five evaluation criteria; for each criterion, select the two best images. Please make sure to select exactly two images! The selected pair is not ranked.
